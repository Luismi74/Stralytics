# Configuration Setup

## Overview

This application uses a JSON-based configuration system to manage sensitive credentials and app settings.

## Setup Instructions

### 1. Create Your Config File

Copy the example config:

```bash
# The config.example.json is already provided
# Create your actual config.json file
cp assets/config.example.json assets/config.json
```

### 2. Add Your Strava Credentials

Edit `assets/config.json` and replace the placeholder values:

```json
{
  "strava_client_id": "YOUR_ACTUAL_CLIENT_ID",
  "strava_client_secret": "YOUR_ACTUAL_CLIENT_SECRET",
  "redirect_url": "stralytics://callback",
  "callback_scheme": "stralytics"
}
```

**Where to get your Strava credentials:**
1. Go to https://www.strava.com/settings/api
2. Create an application or use an existing one
3. Copy your Client ID and Client Secret

## Configuration Model

The configuration is defined in `lib/core/config/models/app_config.dart`:

```dart
@JsonSerializable()
class AppConfig {
  final String stravaClientId;
  final String stravaClientSecret;
  final String redirectUrl;
  final String callbackScheme;
}
```

Serialization code is auto-generated by `build_runner` in `app_config.g.dart`.

## Usage

### Load Config at App Startup

```dart
void main() async {
  WidgetsFlutterBinding.ensureInitialized();
  
  // Load configuration
  await ConfigService.loadConfig();
  
  runApp(const MyApp());
}
```

### Access Config

```dart
// Get cached config (throws if not loaded)
final config = ConfigService.getConfig();
print(config.stravaClientId);

// Or load fresh
final config = await ConfigService.loadConfig();
```

## Regenerating Serialization Code

If you modify `app_config.dart`, regenerate the serialization code:

```bash
fvm flutter pub run build_runner build --delete-conflicting-outputs
```

## File Structure

```
assets/
  config.json           # Your actual config (gitignored)
  config.example.json   # Template (tracked in git)

lib/core/config/
  models/
    app_config.dart     # Config model with @JsonSerializable
    app_config.g.dart   # Generated serialization code
  services/
    config_service.dart # Service to load and cache config
```

## Important Notes

⚠️ **Never commit config.json** - It contains your secret credentials

✅ **Always update config.example.json** - When adding new config fields

🔒 **Keep secrets secure** - config.json is automatically gitignored
